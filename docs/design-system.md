# Design System

## Creative direction

**Malta modernism × Mediterranean editorial × botanical identity**

The site should feel:
- custom, not templated
- editorial, not "wedding website"
- sophisticated but playful
- architectural but organic
- Mediterranean without becoming generic Amalfi
- Scottish × Mexican × Maltese without relying on flags or clichés

## Palette

| Token | Hex | Use |
|---|---|---|
| Limestone | `#E7D5BA` | Main canvas |
| Harbour | `#295569` | Large contrast sections, typography |
| Terracotta | `#AF6745` | Hero accents / identity moments |
| Sandstone | `#C99B71` | Secondary neutral |
| Turquoise | `#328B87` | Small sea-glass accents |
| Cream | `#F5EEE4` | Reversed text / warm white |
| Ink | `#17303A` | Main dark text |

## Logo

Primary identity: **thistle + agave**.

Use the mark as part of the page composition rather than repeatedly stamping it like a corporate logo.

## Photography

Three visual worlds:
1. **Puerto Escondido** — sunset, sand, intimacy
2. **Malta** — sea, limestone, Grand Harbour, dgħajsa
3. **Villa Bighi** — architecture, heritage, greenery

Photography should be treated editorially:
- large crops
- asymmetry
- overlap
- occasional full-viewport images
- minimal conventional gallery grids

## Motion

Use motion selectively:
- masked image reveals
- pinned text with changing imagery
- subtle parallax
- oversized typography moving at different speeds
- occasional horizontal sequence
- logo elements revealing independently

Avoid:
- every section fading upward
- excessive hover effects
- generic template transitions
