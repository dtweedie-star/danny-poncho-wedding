# Danny & Poncho — Wedding Website

**Malta · 20 May 2028**

A custom editorial wedding website for Danny & Poncho.

## Creative direction

**Malta modernism × Mediterranean editorial × botanical identity**

Visual language:
- warm Maltese limestone
- deep Grand Harbour blue
- terracotta
- sandstone
- sea-glass turquoise
- botanical greenery
- thistle + agave identity
- Puerto Escondido engagement photography
- Villa Bighi / Grand Harbour imagery

## V1 — Save the Date

1. Editorial opening
2. Live countdown to the second
3. Engagement photography
4. Scotland × Mexico × Malta identity moment
5. Villa Bighi reveal
6. Save-the-date closing panel

Later versions will add travel, hotels, Malta recommendations, weather, RSVP, dietary/allergy requirements, flight details, song suggestions, marriage advice and wedding predictions.

## Local development

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Assets

Final assets belong in `public/assets/`.

Suggested filenames:
- `logo-primary.svg`
- `logo-mark.svg`
- `save-the-date.mp4`
- `engagement-01.jpg`
- `engagement-02.jpg`
- `engagement-03.jpg`
- `villa-bighi.jpg`
- `grand-harbour.jpg`

Do not commit private guest data such as RSVP exports, dietary details, phone numbers or flight information.
